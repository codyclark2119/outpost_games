# WPN Marketing Assets Access Guide

> **Current usage note:** `public/wpn-assets/` is now used specifically for promotional/marketing posters (e.g. the homepage Featured Items banner), not per-set product photography — phase one of the product page rollout uses Square's own hosted product photos instead. This guide's steps for sourcing official WPN materials still apply; once the shop carries a wider selection of stock, set-based product imagery may be reintroduced here.

## Overview
As a Wizards Play Network (WPN) member store, The Outpost Games has access to official marketing materials, promotional assets, and resources that can be used legally on your website and in-store materials.

## Accessing WPN Assets

### Step 1: Log Into WPN Portal
1. Visit: **https://wpn.wizards.com/en**
2. Click "Sign In" (top right corner)
3. Use your WPN store credentials to log in

### Step 2: Navigate to Marketing Materials
Once logged in:
1. Go to **Marketing Materials** section from the main navigation
2. Or directly visit: **https://wpn.wizards.com/en/marketing-materials**

### Step 3: Browse Available Assets
You'll find materials organized by:
- **Current Sets** (e.g., Lorwyn Eclipsed, Marvel Super Heroes)
- **Product Lines** (Draft Night, Theme Decks, etc.)
- **Event Types** (Prerelease, Store Championships)
- **General MTG Branding**

## Types of Assets Available

### Digital Marketing Assets
- **Social Media Graphics** - Pre-sized for Facebook, Instagram, Twitter
- **Web Banners** - Various sizes for website headers and ads
- **Email Templates** - Pre-designed event announcements
- **Digital Posters** - Downloadable event flyers

### Print-Ready Materials
- **In-Store Posters** - High-resolution PDFs for printing
- **Promotional Flyers** - Event announcements and schedules
- **Table Tents** - Product information displays
- **Window Clings** - Store window decorations

### Product Images
- **Set Logos** - Official set symbols and branding
- **Booster Pack Images** - Product photos
- **Card Previews** - Featured cards from new sets
- **Promo Card Images** - Store promotional materials

### Video Content (Embed Only)
- **Set Trailers** - Official preview videos
- **Gameplay Videos** - Tournament coverage
- **Product Spotlights** - New release showcases

**Note:** Videos must be embedded from official sources (YouTube, Twitch) - you cannot download and re-host them.

## What You CAN Use From WPN

✅ **All WPN Marketing Kit Materials**
- Pre-approved for WPN store use
- No additional permissions needed
- Can be used on website, social media, in-store

✅ **Official Product Photography**
- Booster packs, bundles, and sealed products
- Use as-is without modification

✅ **Set Logos and Branding**
- When provided in marketing kits
- Must be used as provided (no alterations)

✅ **Event Templates**
- Schedule templates for tournaments
- Prerelease materials
- Store Championship assets

## What You CANNOT Use (Even as WPN Member)

❌ **Mana Symbols** - {W}{U}{B}{R}{G} are trademarked
❌ **Tap Symbol** - {T} is a registered trademark
❌ **Modified Logos** - Don't alter official branding
❌ **Video/Music Downloads** - Must embed, not re-host
❌ **Card Images for Counterfeit** - Never create proxy cards

## Best Practices for Website Use

### Images
1. Download high-resolution versions from WPN portal
2. Optimize for web (compress without losing quality)
3. Add proper alt text for accessibility
4. Keep aspect ratios intact

### Logos
1. Use PNG files with transparent backgrounds
2. Maintain minimum size requirements
3. Don't place on busy backgrounds
4. Ensure adequate clear space around logos

### Event Promotion
1. Use official event artwork from current marketing kit
2. Update regularly with new set releases
3. Include event details (date, time, format, fee)
4. Link to WPN event calendar when appropriate

## Seasonal Marketing Kits

WPN releases comprehensive marketing kits for major sets:
- **2-3 months before release** - Teaser materials
- **6 weeks before** - Full marketing kit available
- **Release week** - Additional launch materials
- **Post-release** - Ongoing support materials

3. Join WPN store social media groups
4. Attend WPN store webinars

## Legal Requirements

### Attribution
Always include when using MTG-related content:
```
"This content is unofficial Fan Content permitted under the Fan Content Policy. 
Not approved/endorsed by Wizards. Portions of the materials used are property 
of Wizards of the Coast. ©Wizards of the Coast LLC."
```

### WPN Assets Exception
WPN-provided marketing materials don't need the Fan Content disclaimer since they're official resources, but it's still good practice to include copyright notices.

### Do Not
- Sell or license MTG imagery
- Create unofficial products
- Modify trademarked elements
- Remove existing copyright notices
- Use competitor branding alongside MTG materials

## Tips for Using Assets Effectively

1. **Keep It Current** - Update homepage graphics with each new set
2. **Consistent Branding** - Use matching assets across all pages
3. **Mobile-Friendly** - Ensure images scale properly on mobile devices
4. **Performance** - Optimize image sizes for fast loading
5. **Accessibility** - Always include descriptive alt text

## Getting Help

### WPN Support
If you need specific assets or have questions:
1. Log into WPN Support: https://support.wizards.com/
2. Select "WPN Store Support"
3. Choose "Marketing Materials" category
4. Submit your request

### Response Time
- General questions: 2-3 business days
- Urgent event support: 1 business day
- Technical issues: 24-48 hours

## Additional Permissions

If you want to use content NOT available in WPN materials:
1. Contact WPN Support through official channels
2. Clearly describe your intended use
3. Wait for written approval before proceeding
4. No response ≠ approval
